01

What the benchmark found

Three things matter more than a ranking.

Technical

Code review separated the field.

Most runs found the two planted defects in the limiter. DeepSeek’s thick review missed the bigger one: prune compares an object to a number, so it never runs. It caught the reset bug, but not the type mismatch.

See the two reviews →
Fidelity

Two runs are not directly comparable.

Muse Spark’s saved files were rewritten, not copied: four artifacts in run 1 and seven in run 2. Treat those runs as process demos, not as the model’s one-shot output.

See a trimmed artifact beside a clean one →
Process

The cleanest runs were the quietest.

HY4 Flash and Claude Haiku 5.5 (run 2) used no subagent tools and saved every file exactly. DeepSeek’s subagents made 363 tool calls, browser screenshots included. GPT’s loaded 29 skills.
