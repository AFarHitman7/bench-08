[blocker] reset() — splices the array while iterating forward with `i++` — removing at index `i` shifts the next matching hit into `i`, which is then skipped, so consecutive hits for the same key survive the reset — iterate from the end backwards or rebuild with `filter`.

[minor] prune() — assumes `hits[0]` is the oldest, which only holds if `now()` is monotonic; a clock that moves backwards leaves stale hits unpruned — document/validate the monotonic-clock requirement or locate the minimum time explicitly.
